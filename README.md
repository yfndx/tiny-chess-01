A 3,460-byte Python chess engine: 0x88 board, alpha-beta with iterative deepening, quiescence search (captures + check evasions), transposition table (Zobrist), null-move pruning, and MVV-LVA / killer / history move ordering. Practice Elo 1,654 on the 6-game trial (5 wins, 0 draws, 1 loss) — well above the 1,154 floor and the ~1,365 sunfish baseline.

## Run it

```sh
python3 -P -s main.py
```
